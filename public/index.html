Dynamic GitHub Badges

Generate customizable SVG badges and track GitHub profile views using a simple, developer-friendly API. Integrate dynamic profile statistics into your GitHub README in seconds.

BASE URL

API Endpoints

Two simple endpoints to generate badges and retrieve profile statistics.

GET

/api/badge/:username

Generates a customizable SVG badge for a GitHub username. Every request increments the profile view counter and returns the badge as an SVG image.

/api/badge/YOUR_GITHUB_USERNAME
GET

/api/stats/:username

Retrieves the current profile view statistics in JSON format. This endpoint also increments the counter on each request.

/api/stats/YOUR_GITHUB_USERNAME

Customize Your Badge

Use query parameters to personalize your badge.

Parameter Description Available values Default
label Text displayed on the left side Any text PROFILE VIEWS
color Badge counter color blue, green, red, orange, purple, gray blue
style Badge appearance flat, gradient gradient

Example Requests

Try different combinations of parameters.

Green badge 
/api/badge/YOUR_GITHUB_USERNAME?color=green&style=flat
Purple badge 
/api/badge/YOUR_GITHUB_USERNAME?color=purple&style=gradient
Custom label 
/api/badge/YOUR_GITHUB_USERNAME?label=VISITORS&color=blue

GitHub README Integration

Add your badge to your GitHub profile README using Markdown.

Markdown 
![Profile Views](https://github-badge-generator.onrender.com/api/badge/YOUR_GITHUB_USERNAME)
HTML 
<img src="https://github-badge-generator.onrender.com/api/badge/YOUR_GITHUB_USERNAME" alt="Profile Views">

Replace YOUR_GITHUB_USERNAME with your GitHub username.

Getting Started

Start generating your first badge with a single request.

Example request 
GET /api/badge/YOUR_GITHUB_USERNAME

The API automatically creates a profile record if one does not already exist, increments its view count, and returns an SVG badge.
